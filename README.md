# AI4EDU-SPORT — strona rekrutacyjna

## Pliki do wgrania do repozytorium GitHub Pages
- `index.html`
- `style.css`
- folder `assets/`

## Co trzeba później zmienić
1. W `index.html` znajdź:
   `const REDCAP_URL = "#";`
   i wstaw właściwy link do formularza REDCap.
2. Zmień adres e-mail `projekt@example.com` na właściwy.
3. Podmień robocze treści po ustaleniu szczegółów pilotażu.

Po wgraniu plików do repozytorium `ai4edu-sport.github.io` strona będzie publikowana przez GitHub Pages.
